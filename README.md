# Used Cars Cost Prediction

Machine learning project to predict used car prices using regression models 
on the Audi used cars dataset, built during a Data Science & ML internship at Acmegrade.

## Dataset
Audi used cars dataset (audi.csv) — includes features like model, year, mileage, 
fuel type, transmission, engine size, etc.

## Models Used
- Linear Regression
- Random Forest Regressor
- ExtraTreesRegressor
- CatBoostRegressor

## Approach
- Data cleaning and preprocessing (handling categorical variables, feature scaling)
- Trained and compared multiple regression models
- Evaluated model performance to identify the best predictor for car price

## Tools
Python, pandas, NumPy, scikit-learn, CatBoost

## How to Run
1. Open `Used_Cars_Cost_Prediction.ipynb` in Jupyter/Colab
2. Ensure `audi.csv` is in the same directory
3. Run all cells
